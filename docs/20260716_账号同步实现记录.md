# BiteSmart 账号同步实现记录

## 已完成

- 新增 `user_third_party_identity` 身份绑定表。
- 增加微信小程序登录接口：`POST /api/auth/wechat-login`。
- 增加已登录用户绑定微信接口：`POST /api/auth/wechat-bind`。
- 新用户微信登录自动创建 `sys_user`，角色为普通用户，注册来源为小程序。
- 已绑定微信用户登录后返回统一 JWT，后续业务数据通过同一个 `userId` 查询。
- 小程序端新增 JWT 存储、统一请求封装和微信登录页。

## 配置

在后端环境变量中配置：

```text
WECHAT_MINI_APP_ID=小程序 AppID
WECHAT_MINI_APP_SECRET=小程序 AppSecret
```

小程序端开发者工具本地请求地址当前为：

```text
http://localhost:8080/api
```

真机调试时需要改为可访问的后端 HTTPS 地址或局域网地址，并在微信公众平台配置合法域名。

## 当前限制

- 未配置 AppID 和 AppSecret 时，微信登录接口会返回配置错误，不会伪造登录成功。
- 真实微信支付尚未接入。
- 当前只实现了微信身份绑定基础能力，尚未制作 PC 端“绑定微信”操作页面。
