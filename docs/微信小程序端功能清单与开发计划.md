# BiteSmart 微信小程序端功能清单与开发计划

## 一、文档目的

本文档用于记录 BiteSmart 微信小程序端的功能范围、页面拆分、后端接口现状、待解决问题和开发进度。

小程序端包含三类移动端角色：

1. 普通用户
2. 商家
3. 配送员

管理员继续使用 PC 管理端，不纳入本小程序端范围。

## 二、当前项目状态

| 项目 | 当前状态 |
| --- | --- |
| 小程序目录 | `BiteSmartMin` |
| 小程序技术栈 | 微信原生小程序 + TypeScript + Sass |
| 当前页面 | 初始化模板 `index`、`logs` |
| 业务页面 | 尚未开始开发 |
| 小程序 API 封装 | 尚未开始开发 |
| 后端业务接口 | 用户、商家、配送员主要接口已具备 |
| PC 端参考 | 已有用户端、商家端和管理端页面及 API 文件 |

## 三、用户端功能

### 1. 微信登录

- 微信授权登录
- 首次登录绑定用户
- 登录失效重新登录
- 用户协议与隐私授权

> 当前后端只有账号密码登录 `/api/auth/login`，需要补充微信 `code2Session` 登录接口。

### 2. 问卷式健康档案填写

- 基础信息
- 性别、年龄、身高、体重
- 健康目标
- 饮食偏好与忌口
- 过敏食材
- 运动频率
- 健康档案修改

参考接口：`/api/user/profile`、`/api/users/me`

### 3. AI 食谱推荐

- 每日推荐食谱
- 个性化菜品推荐
- 健康套餐推荐
- 推荐原因和营养说明
- 推荐菜品直接加入购物车

参考接口：`/api/ai/recommend`

### 4. AI 智能实时对话

- 营养问题咨询
- 饮食建议
- 减脂、增肌、控糖等专项指导
- 对话历史
- 推荐结果跳转菜品或套餐

参考接口：`/api/ai/chat`、`/api/ai/chat/history`

### 5. 菜品浏览

- 菜品分类
- 菜品搜索
- 菜品列表
- 菜品详情
- 图片、价格、库存
- 热量、蛋白质、脂肪、碳水
- 适宜人群和禁忌说明
- 加入购物车

参考接口：`/api/dishes`、`/api/dishes/categories`

### 6. 套餐购买

- 套餐列表
- 套餐详情
- 套餐营养信息
- 套餐适宜人群
- 套餐内菜品查看
- 套餐菜品更换
- 更换后的价格和营养重新计算
- 立即购买或加入购物车

参考接口：`/api/combos`、购物车套餐替换接口

### 7. 购物车管理

- 菜品和套餐统一展示
- 增加数量
- 减少数量
- 删除商品
- 勾选或取消勾选
- 套餐内容更换
- 商品金额和配送费计算
- 去结算

参考接口：`/api/cart`

### 8. 在线下单

- 确认订单页面
- 收货地址选择
- 地址新增、编辑、删除
- 联系人和联系电话
- 配送方式选择
- 配送时间
- 订单备注
- 订单金额确认
- 提交订单

参考接口：`/api/orders`、`/api/user/addresses`

### 9. 在线支付

- 支付方式选择
- 支付宝 H5 支付
- 模拟微信支付
- 支付中状态
- 支付成功页面
- 支付失败和重新支付
- 支付结果同步订单状态

> 当前后端已有支付宝相关服务，但小程序支付流程尚未完整确认，需要明确支付宝 H5、模拟微信支付或真实微信支付方案。

### 10. 我的订单

- 全部订单
- 待支付
- 待接单
- 备餐中
- 配送中
- 已完成
- 已取消
- 订单详情
- 菜品和套餐明细
- 收货信息
- 订单备注
- 未接单订单取消
- 再次购买
- 去评价

参考接口：`/api/orders`

### 11. 配送实时定位

- 配送状态时间线
- 配送员信息
- 配送员电话
- 当前经纬度
- 地图展示
- 配送路线
- 预计送达时间
- 配送轨迹刷新

参考接口：`/api/delivery/tracking/{orderId}`

### 12. 饮食记录

- 添加饮食记录
- 早、中、晚餐记录
- 食物和菜品记录
- 热量、蛋白质等营养数据
- 饮食记录列表
- 编辑和删除记录
- 每日饮食汇总

参考接口：`/api/health/diet`

### 13. 运动记录

- 运动类型
- 运动时长
- 运动距离
- 消耗热量
- 运动记录列表
- 编辑和删除记录
- 每日运动汇总

参考接口：`/api/health/exercise`

### 14. 体重变化

- 体重记录
- 体脂等扩展信息
- 体重历史列表
- 体重趋势图
- 周、月、季度筛选
- 健康目标对比

参考接口：`/api/health/weight`

### 15. 评论反馈

- 订单评价
- 菜品评价
- 商家评价
- 配送员评价
- 星级评分
- 文字评价
- 图片评价
- 我的评价
- 投诉与意见反馈

参考接口：`/api/reviews`、`/api/reviews/my`、`/api/complaints`

### 16. 我的会员

- 当前会员信息
- 会员等级
- 会员权益
- 会员套餐
- 购买会员
- 会员续费
- 会员到期时间
- 购买历史

参考接口：`/api/user/membership`

### 用户端辅助页面

- 首页
- 个人中心
- 公告列表和公告详情
- 地址管理
- 投诉记录
- 设置和退出登录

### 2. 接单管理

- 待接单列表
- 订单接单
- 订单拒绝
- 接单时间
- 任务状态筛选
- 当前配送任务

参考接口：`/api/driver/tasks`、`/api/driver/tasks/{id}/accept`

### 3. 配送订单查看

- 用户地址
- 用户电话
- 订单商品
- 订单备注
- 取餐码
- 预计送达时间

### 4. 配送状态更新

- 待取餐
- 已取餐
- 配送中
- 已送达
- 状态时间线

参考接口：`/api/driver/tasks/{id}/pickup`、`/api/driver/tasks/{id}/deliver`

- 今日收入
- 本周订单量和收入

- 历史结算记录
- 收入趋势

### 8. 异常上报

- 地址错误

- 商品损坏
- 自定义异常说明
- 异常提交记录

参考接口：`/api/driver/tasks/{id}/exception`

### 9. 服务评价查看

- 用户评价列表
- 配送评分
- 评价详情

- 历史服务记录

### 配送员端辅助页面

- 配送员首页
- 当前任务详情
- 配送任务历史
- 个人中心
- 在线状态开关

## 六、当前待解决问题

1. 增加微信登录接口，例如 `/api/auth/wechat-login`。
2. 明确支付宝 H5、模拟微信支付和真实微信支付的实现范围。
3. 确认配送位置采用轮询还是 WebSocket 推送。
4. 确认评论是否分别支持菜品、商家和配送员评价。
5. 统一后端分页返回结构，避免页面分别处理不同的数据层级。
6. 小程序端需要建立统一请求封装、Token 管理、错误处理和角色路由。
